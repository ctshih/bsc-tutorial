BSC 訓練課程

每一集都是一次真實的工作紀錄——每一步的指令、Agent 當下怎麼想怎麼做、 以及當時的畫面，包括中間失敗的地方。

這門課在做什麼

示範怎麼跟 AI Agent 一起做研究工作。五集是同一條真實的工作線： 先把一批研究論文交給 Agent，建成一座有規則、可維護、會成長的知識庫（EP01–03）； 然後反過來用這座知識庫——把主題頁變成一門課（EP04）、把論文條目當規格，讓 Agent 復刻出論文的程式（EP05）。

每一集都是真實工作階段的紀錄：每一步的指令、Agent 怎麼想怎麼做、撞了什麼牆、哪些方案被否決—— 包括做壞被退回重做的部分。素材恰好是神經科學的論文，但方法不綁定領域： 你可以拿自己領域的文獻，照同樣的流程走一遍。

要學的不是某個工具的操作，是分工：規格、邊界、驗收是人的；執行的迴圈是 Agent 的。 五集看完，你會知道哪些決定不該交出去，以及交出去的部分要怎麼驗收。

教材網頁可回頭查的完整紀錄。每一步的指令、Agent 動作、截圖與教學重點。
教學影片十來分鐘的敘事版，只講骨幹與為什麼。建議先看影片再讀網頁。
隨堂測驗十題單選，答完立刻看對錯與理由。自我練習，不記分。
EP01

建置 LLM Wiki 的第一步

從一份 gist 到第一篇論文筆記。認識三層架構、看 Agent 自己解決工具問題、 學會在它做錯的時候喊停——那句「作廢」是全集最該學的一步。

建議的學習順序

  1. 先看影片建立整體概念，十來分鐘。
  2. 再讀教材網頁——影片只講骨幹，網頁才有每一步的完整指令與 Agent 的實際動作。
  3. 做測驗。答錯的當下看理由，比最後看分數有用得多。
  4. 照著網頁末尾的練習自己動手做一遍。這門課的設計就是要你自己做決定。
